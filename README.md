## Featured projects

### [LeadOptAI](https://github.com/julianariveracamacho/LeadOptAI-Overview)
Chemistry-aware Transformer research for **molecular-property prediction** and **SMILES infilling**, developed during my master’s thesis at UKE.

- Built joint discrete/continuous representations and masked prediction objectives.
- Implemented SMARTS functional-group and RDKit BRICS masking.
- Developed training/evaluation workflows and compared molecular language-model baselines.

The public overview explains the project; implementation and unpublished results remain private.

### [Protein–Ligand Stability Analysis](https://github.com/julianariveracamacho/protein-ligand-stability-analysis)
Protein-stability and docking-data analysis for **pharmacological-chaperone research** at UKE.

- Developed residue-level visualizations, pose comparisons and compound interaction summaries.
- Analyzed supplied research inputs using collaborator-provided structural utilities.
- Includes a **[runnable synthetic example](https://github.com/julianariveracamacho/protein-ligand-stability-analysis/tree/main/examples/synthetic)** with input validation, compound-level statistics and a generated figure.
